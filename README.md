# Loadout

Ranked AI tool picks for builders and players. Live at https://eva-suggestions.vercel.app

Rankings, releases and patch notes live in `data.json`. `build.py` turns them into `index.html`, `llms.txt`, `robots.txt` and `sitemap.xml`:

    python3 build.py

Status: launch draft. Picks are editorial and have not been through a test harness yet.
